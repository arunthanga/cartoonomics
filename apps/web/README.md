# `web` — cartoonization frontend (§7.6)

The user-facing app that turns a **CartoonSpec** into an accessible, animated
cartoon. It is the visual soul of the product (`requirements.md` §7.3–§7.6, §9).

## Today: framework-free reference renderer

This folder currently holds a dependency-free renderer that proves the
CartoonSpec contract end-to-end:

- `index.html`, `cartoon.css`, `cartoon.js` — load and draw a spec.
- `cartoon_spec.json` — the demo payload, regenerated by `make demo`.

Run it from the repository root:

```bash
make serve   # regenerates the spec, then serves http://localhost:8000
```

## Target: React + TypeScript + Vite (ADR-0001 §4)

The production app replaces the reference renderer **in place**, keeping the same
contract:

```text
apps/web/
├─ src/
│  ├─ components/   # cartoon primitives (FR-6.1): money-stream, coin-stack, see-saw, ...
│  ├─ pages/        # the §8 information architecture (Home, Compare, Company, My Cashflow, ...)
│  └─ lib/          # CartoonSpec client + hooks
├─ stories/         # Storybook — the primitive library (ADR-0001 §4)
└─ package.json
```

**Contract source of truth:** import generated CartoonSpec types from
`packages/contracts` — never re-declare the shape here. Motion must honour
`prefers-reduced-motion` and provide a static equivalent (A11Y-5), and every
cartoon must offer "Show the numbers" (FR-6.2).
